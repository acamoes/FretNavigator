# FretNavigator

A guitarist's study and songbook tool: fretboards, tabs and chord boxes that
show where notes and chords live on the neck of a six-string guitar.

## Language

### Tunings

**Tuning**:
The pitch of each open string, lowest string first.
_Avoid_: preset, string set

**Tuning family**:
The group a tuning belongs to — Standard, Drop, Open or Other — named for how
it relates to E Standard.

**Standard tuning**:
E A D G B E, or that same set of intervals moved down so every string drops by
the same amount; named by its lowest string ("Eb Standard", "C# Standard").
_Avoid_: half-step down, down-tuned, "1.5 steps down"

**Drop tuning**:
A standard tuning with only the lowest string lowered a further whole step;
named by that string's new note ("Drop D" is E Standard dropped, "Drop C#" is
Eb Standard dropped).

**Open tuning**:
A tuning whose open strings, strummed together, sound a major chord; named by
that chord ("Open G").

**Sounding pitch**:
The note actually heard at a string and fret in the current tuning. Fretboards
always show sounding pitches, never the note the same shape would give in E
Standard.
_Avoid_: shape name, written pitch
